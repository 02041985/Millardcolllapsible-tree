# School Facilities Command Center

A rapid-response maintenance and resource management application for a school campus.

## Included
- 50 classrooms seeded in Supabase
- Offices, staff toilets, student toilets, corridors, laboratories, library, canteen and playing grounds
- Asset/equipment inventory
- Teacher one-click assistance/repair request
- 30-minute SLA timer per request
- Facilities manager live response board
- Vendor assignment and status tracking fields
- Supabase Realtime for live request updates

## Stack
- Static HTML/CSS/JavaScript frontend
- Supabase Database + Realtime
- Deployable to Vercel or GitHub Pages

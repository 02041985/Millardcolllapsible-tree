# Millard Collapsible Tree

A lightweight interactive hierarchical tree for exploring structured data.

## Features

- Expand/collapse nodes with a single click
- Double-click a node to open its details
- Search nodes
- Expand all / collapse all controls
- Responsive layout
- No build step required

## Run

Open `index.html` in a browser, or deploy the repository as a static site on Vercel/GitHub Pages.

## Next integration

The sample hierarchy in `app.js` is intentionally separated from the rendering logic so it can be replaced by Excel, CSV, Google Sheets, or Supabase data.
